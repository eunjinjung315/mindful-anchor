# 마음챙김 — 하루 한 문장

마음챙김과 동기부여를 위한 작은 웹앱. 니체 · 박웅현 · 법정스님 · 보만스님의 문장 20개를 골라 담았습니다.

**바로 쓰기:** https://eunjinjung315.github.io/mindful-anchor/

## 들어 있는 것

- **오늘** — 작가별 필터, 오늘의 문장, 짧은 생각 한 줄, 담기 (브라우저에 저장)
- **호흡** — 60초 숨 고르기 (4초 들이마시기 · 4초 멈추기 · 6초 내쉬기)
- **기록** — 기분 태그와 함께 내 생각 한 줄 남기기, 담은 문장 모아보기

## 아이폰에서 앱처럼 쓰기

Safari로 링크를 열고 **공유 → 홈 화면에 추가**를 누르면 앱 아이콘처럼 실행됩니다.

## 고치기

`index.html` 한 파일에 스타일과 스크립트가 모두 들어 있습니다. 이 파일을 바꿔 올리면(Push) 1분 안에 위 주소에 반영됩니다.
